# Contributing

Thanks for helping improve this repo. It is the content source of [thecoding.dev](https://thecoding.dev), a Mintlify site that rebuilds automatically on every push to `main`.

## Report something

Issue templates cover the common cases (blank issues are disabled):

- [Bug report](https://github.com/vinibarbosabr/thecoding-docs/issues/new?template=bug-report.yml): broken links, rendering problems, factual errors
- [Improvement](https://github.com/vinibarbosabr/thecoding-docs/issues/new?template=improvement.yml): suggestions for pages, navigation, or structure
- [Question](https://github.com/vinibarbosabr/thecoding-docs/issues/new?template=question.yml): anything else

For business, pricing, or partnership inquiries, use the [contact page](https://thecoding.dev/contact) instead of issues.

## Leave a recommendation

Clients and collaborators can leave a public endorsement through the [endorsement issue form](https://github.com/vinibarbosabr/thecoding-docs/issues/new?template=endorsement.yml). No fork or pull request is needed. After review, approved recommendations are published to the [Recommendations & Endorsements](https://thecoding.dev/endorsements) page and the issue is closed.

Keep recommendations factual and specific to the work. Do not include confidential or private information.

## Pull requests

Small fixes (typos, broken links, formatting) can go straight to a pull request.

1. Fork or branch from `main`.
2. Preview locally with `npx mint@latest dev` and open <http://localhost:3000>. The CLI needs Node >= 18.
3. Keep one concern per PR and use a Conventional Commit prefix: `docs:`, `feat:`, `fix:`, or `chore:`.

For content style (voice, headings, formatting), follow the conventions in [AGENTS.md](AGENTS.md).

## Do not submit

- Secrets, keys, or credentials
- Private client data or NDA-restricted details
