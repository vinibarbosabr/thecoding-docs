# Docs Overhaul | Buyer Path | 2026-09

Documenting the Docs Overhaul, improving the **buyer path** on thecoding.dev.

---

## Goal

Improve the buyer path on thecoding.dev: make it fast and obvious
for a web3/crypto team to understand the offer, pick a first purchase,
and start.

## Success test (release criteria)

- A founder can tell what to buy in 30 seconds.
- The first purchase is obvious ($350 Discovery, credited forward).
- Proof is work — not follower counts or stake TVL.
- Nav matches the offer, not the résumé.
- Every old URL still works.

## Scope

This overhaul is information architecture + sales-path pages + proof.
It is not a visual redesign, not a new brand, and not new services.
